# Tuberías: ver cada transformación

## Explorador
Abrí [[Recursos Visuales/linux-tuberias.html|Explorador de tuberías]] en un navegador. Incrustación HTML pendiente de identificar el plugin.

1. Elegí **Original** y avanzá por entrada → campo → filtro → conteo. Resultado: **2**.
2. Elegí **Repetidas**: hay **3 registros** que empiezan por `170.`, pero solo **2 IPs diferentes** entre ellos.
3. Elegí **Espacios variables**: compará `cut` y `awk`; el primero no agrupa espacios consecutivos.
4. Elegí **Vacío**: el conteo es **0**; no hay registros para un porcentaje.

Es una simulación didáctica con entradas fijas y comandos visibles; no ejecuta una terminal. Se reutiliza el ejemplo de [[Temas/Linux/07_Texto_y_tuberias_Gemini]]; su diagrama sigue siendo la explicación estática.
