# Resultados de agentes

Guardar aquí investigaciones, transcripciones, borradores, registros y hallazgos. Cada salida indica fecha, tarea, fuentes y estado de revisión. El registro de actividad describe acciones realmente realizadas; no implica que una tarea haya terminado si no se verificó el resultado. Los hallazgos deben revisarse antes de repetir el mismo flujo.
